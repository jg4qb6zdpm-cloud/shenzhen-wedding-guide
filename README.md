# 深圳备婚指南

> 一份面向深圳家庭的备婚项目手册：把“要办成什么样、要花多少钱、由谁在什么时间完成”说清楚。

**主格式：** Markdown  
**版本：** v1.0（2026年10月）  
**适用范围：** 计划在深圳举办婚礼的内地居民家庭  
**文档性质：** 家庭内部参考，不构成法律、税务、投资或医疗建议

## 核心结论（先看这五条）

1. **先定规格和预算上限，再看酒店。**
2. **桌数是最大的成本杠杆。** 每减 5 桌，通常释放 3–8 万元。
3. **合同附件比正文更重要。** 人员、设备、菜单、布置、交付时间都要写进附件。
4. **留 10% 备用金。**
5. **当天只有一个总指挥。**

## 四种规格

| 档位 | 一句话定位 | 宾客/桌数 | 婚礼执行预算（不含婚房/购车） |
|---|---|---|---|
| **S1 简约登记型** | 领证 + 至亲餐叙 | 20–60人 / 2–6桌 | 5–15万元 |
| **S2 品质婚宴型** | 标准酒店婚宴，完整但不过度定制 | 100–200人 / 10–20桌 | 25–50万元 |
| **S3 高端定制型** | 五星/户外定制，重视设计与体验 | 180–300人 / 18–30桌 | 60–120万元 |
| **S4 家族旗舰型** | 地标场地、多日或目的地婚礼 | 250–500人 / 25–50桌 | 150–300万元+ |

> 预算不含婚房、购车、彩礼/嫁妆、蜜月。价格为 2026年10月深圳市场参考，实际随日期/区域/品牌浮动。

## 怎么用

### 1. 只读/分享

直接打开 **[深圳备婚指南.md](深圳备婚指南.md)**。支持 GitHub、Typora、Obsidian、VS Code、飞书/Notion 导入等 Markdown 阅读器。

### 2. 打印/现场发

打开 **[深圳备婚一页纸.md](深圳备婚一页纸.md)**，打印 A4；或复制到 Word/WPS 排版后打印。

### 3. 填预算/清单

复制 **[templates/预算与清单模板.md](templates/预算与清单模板.md)** 为 `我的备婚预算与清单.md`，逐项填写。表格可直接在 Typora/Obsidian/飞书中编辑。

### 4. 修改内容

编辑 `docs/*.md`，然后重新拼装：

```powershell
python scripts/build_master_md.py
```

> 需要 Python 3.10+。脚本只做文件拼接，不依赖第三方库。
