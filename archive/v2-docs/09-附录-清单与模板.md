# 09｜附录：一页清单、模板与资料来源

> 这一章可以单独打印。建议把“一页清单”贴在冰箱/办公桌前，每完成一项打勾。

## 9.1 一页纸备婚清单

### A. 决策（T-12～T-11）

- [ ] 完成“一页家庭共识书”：婚期、宾客上限、预算上限、S 档、T 档。
- [ ] 确定总协调人、财务负责人、长辈联络人。
- [ ] 确定彩礼/嫁妆处理原则（收/不收/用途/回礼）。
- [ ] 确认婚房、购车、蜜月是否纳入家庭总投入。
- [ ] 建立预算总表、宾客名单表、供应商对比表。

### B. 登记与婚检（T-12～T-10）

- [ ] 预约免费婚检（提前 1–2 周）。
- [ ] 准备身份证、3 张 2 寸红底合影照。
- [ ] 预约领证（提前 15 天，8:30 放号）。
- [ ] 跨境婚姻文件启动（公证/认证/翻译）。
- [ ] 确认婚假天数与使用期限。

### C. 场地（T-11～T-9）

- [ ] 看 3–5 家场地，填写场地考察表。
- [ ] 对比桌数、层高、柱距、交通、停车、新娘房。
- [ ] 确认服务费、最低消费、备用桌、加桌价、超时费。
- [ ] 把 3 家报价折算成“全包桌价”，不只比桌价。
- [ ] 确认户外雨备/天气条款。
- [ ] 签合同、付定金、保留报价单附件。

### D. 婚策与四大（T-10～T-6）

- [ ] 看 3 家婚策，要求分项报价。
- [ ] 确认当天执行团队姓名/人数。
- [ ] 面试司仪，看完整婚礼视频。
- [ ] 看摄影/摄像完整客片，确认双机/备份。
- [ ] 试妆，确认跟妆人数/时长。
- [ ] 合同写死人员替换/交付/尾款条款。

### E. 婚纱、珠宝、婚车（T-8～T-5）

- [ ] 婚纱定制/租赁下单，确认试穿/取件日期。
- [ ] 新郎西装定制/租赁。
- [ ] 三金/钻戒购买，证书/发票收好。
- [ ] 婚车 6–8 辆，确认车型/时间/超时费。
- [ ] 试穿全套（婚纱+头纱+婚鞋+内衣+配饰）。

### F. 宾客与菜单（T-6～T-4）

- [ ] A/B/C 宾客名单，RSVP 截止。
- [ ] 桌数测算：到场率 + 备用桌。
- [ ] 试菜，确认食材规格/过敏原/预制菜。
- [ ] 确认酒水/开瓶费/服务费。
- [ ] 设计请柬/电子请柬，确认发放时间。

### G. 流程与物资（T-4～T-1）

- [ ] 仪式流程、音乐、视频脚本。
- [ ] 座位表、主桌安排。
- [ ] 伴手礼、喜糖、签到用品。
- [ ] 物资箱编号/清单。
- [ ] 彩排：走位/灯光/话筒/长辈接待。
- [ ] 天气预案/室内备选。

### H. 当天与收尾（T～T+30）

- [ ] 总指挥/角色卡/联系表发到人。
- [ ] 礼金双人保管/保险箱。
- [ ] 影像素材双备份。
- [ ] 尾款/加项核对。
- [ ] 回门/答谢。
- [ ] 影像交付/账目归档。

### I. 婚博会/集中采购（可选，建议婚前 6–10 个月）

- [ ] 列 3 个必买品类，定“今天最多付多少定金”。
- [ ] 带现有报价单和比价表。
- [ ] 只买“可比较、可退、可锁价”的套餐。
- [ ] 订单写清含项、增项单价、保价期、退款条件。
- [ ] 展后 48 小时内完成比价/退单/补条款。

## 9.2 预算与清单模板使用说明

复制 `templates/预算与清单模板.md` 为 `我的备婚预算与清单.md`，即可逐项填写。模板包含 13 个部分：

| 部分 | 用途 |
|---|---|
| **1 总览** | S 档/T 档、桌数、桌价、全包桌价、预算上限、缺口 |
| **2 预算明细** | 按类别列项，记录报价/合同/已付/尾款 |
| **3 桌数与宾客** | 按到场率测算人数/桌数/备用桌 |
| **4 时间线** | T-12 到 T+1 月任务，负责人/截止日/状态 |
| **5 供应商对比** | 3 家场地/婚策/四大横向评分 |
| **6 当天流程** | 分钟级流程，负责人/地点/备注 |
| **7 风险清单** | 概率/影响/应对/责任人 |
| **8 一页共识书** | 婚期/预算/S 档/T 档/礼俗/角色确认 |
| **9 全包桌价对比** | 把 3 家酒店报价折算成同一口径 |
| **10 增项单价表** | 加桌/加片/超时/设备等 20 项单价 |
| **11 婚博会逛展清单** | 出发前/现场/订单/展后 |
| **12 砍价筹码与让步记录** | 每次谈了什么、对方让了什么 |
| **13 签约检查** | 12 项条款逐条打勾 |

**使用顺序：**

1. 先填“1 总览”，确定预算上限、S 档/T 档和桌数。
2. 在“2 预算明细”逐项填报价/合同价；金额可用飞书/Notion/Excel 的表格公式自动求和。
3. 在“3 桌数与宾客”填邀请人数/到场率，核对桌数。
4. 拿到酒店报价后，先填“9 全包桌价对比”，再决定看哪家。
5. 每周更新“4 时间线”和“7 风险清单”。
6. 婚礼前 7 天，用“1 总览”做最终现金流检查。

> 模板是估算工具，不替代合同；所有金额以书面报价为准。

## 9.7 婚博会逛展清单（打印版）

**出发前**

- [ ] 定预算上限和“今天最多付多少定金”（建议 ≤ 2,000–5,000）。
- [ ] 只列 3 个必买品类，其他只拿资料。
- [ ] 带现有报价单、比价表、充电宝、平底鞋。
- [ ] 查展位图，圈 5–8 家目标展商。
- [ ] 不带长辈/不带队，避免现场被推着下单。

**现场**

- [ ] 先扫馆，后谈单；不在第一家坐下。
- [ ] 同一组问题问每家：人员/机位/精修/服装/超时/增项/交付。
- [ ] 只留同配置、同人数、同交付的报价。
- [ ] 付最小定金，订单写“未签约可退/保价到 X 日”。
- [ ] 拍照留证：报价单、订单、承诺、名片。

**订单必须写**

- [ ] 定金/订金性质与退款条件。
- [ ] 价格保护期。
- [ ] 套餐含项与增项单价。
- [ ] 人员姓名/级别、替换条款。
- [ ] 交付时间/修改次数/底片归属。
- [ ] 合同/收款/发票主体一致。
- [ ] 主办方订单保障是否适用。

**展后 48 小时**

- [ ] 订单拍照存档。
- [ ] 同配置比门店价/线上价。
- [ ] 决定留/退/换，退单书面申请。
- [ ] 预约门店看样/试纱/看场地。
- [ ] 把口头承诺补进补充协议。

> 完整工具包见 `templates/婚博会与砍价工具包.md`。

## 9.8 版本与免责声明

- **文档版本：** v2.0（2026 年 10 月）
- **适用范围：** 计划在深圳举办婚礼的内地居民家庭；涉港澳台/华侨/外国人仅作提示，具体以官方清单为准。
- **价格口径：** 2026 年 Q4 深圳市场参考，单位为人民币；桌价为 10 人/桌、仅菜品，含/不含服务费以各表说明为准。
- **免责声明：** 本文不构成法律、税务、投资、医疗建议。涉及婚前财产、股权、跨境婚姻、重大疾病、食品安全等事项，请咨询执业律师、税务师、医生或相关主管部门。
- **使用建议：** 本文是“决策框架 + 执行清单”，不是“标准答案”。每个家庭应按自己的宾客结构、预算、礼俗和风险偏好调整。
