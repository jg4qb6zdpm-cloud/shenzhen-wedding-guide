## 编辑约定

- 每章以 `# 章节号｜标题` 开头；单文件拼装依赖这个格式。
- 二级标题用 `##`，三级用 `###`；不要跳级。
- 表格使用标准 Markdown 管道表；每行列数保持一致。
- 重点内容用 `**加粗**`；不要在标题里使用加粗。
- 引用块 `>` 用于“提示/注意/行动”类 callout；首句可用 `**注意：**` 形式。
- 清单用 `- [ ]`；普通列表用 `- `；编号列表用 `1. `。
- 事实/价格尽量标注 `[A]/[B]/[C]/[D]`，并同步更新 `research/来源清单.md`。
