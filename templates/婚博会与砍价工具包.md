# 婚博会与砍价工具包

> 打印版 ｜ v3.1 ｜ 2026-10 ｜ 和《深圳备婚指南》附录 A“婚博会”、附录 C“谈判”配套使用

## 1. 婚博会 1 页清单

### 出发前

- [ ] 定预算上限，以及“今天最多付多少定金”（建议 2,000–5,000）。
- [ ] 只列 3 个必买品类；其他品类只拿资料，不坐下来谈。
- [ ] 带上现有报价单，作为比价锚点。
- [ ] 打印/保存下面的“展前目标表”和“现场比价表”。
- [ ] 查展位图，圈 5–8 家目标展商，按路线走。
- [ ] 穿平底鞋，带充电宝、水、名片/二维码。
- [ ] 不带长辈、不带队，避免现场被推着下单。

### 现场

- [ ] 先扫馆，后谈单；不在第一家坐下。
- [ ] 用同一组问题问每家：人员、机位、精修、服装、超时、增项、交付。
- [ ] 只留“同配置、同人数、同交付”的报价。
- [ ] 付最小定金，订单写“未签约可退/保价到 X 日”。
- [ ] 拍照留证：报价单、订单、销售承诺、名片。

### 订单必须写

- [ ] 定金/订金性质，未签约是否可退、几天内退。
- [ ] 价格保护期（保价到 X 月 X 日）。
- [ ] 套餐含项：人员/机位/精修/服装/场景/时长。
- [ ] 增项单价：加片、加机位、加桌、超时、差旅、运输。
- [ ] 人员姓名/级别，替换需书面同意。
- [ ] 交付时间/修改次数/底片归属。
- [ ] 合同/收款/发票主体一致。
- [ ] 主办方订单保障是否适用，盖章。

### 展后 48 小时

- [ ] 2 小时内：订单/报价单拍照，建“婚博会订单”文件夹。
- [ ] 24 小时内：同配置比门店价/线上价。
- [ ] 48 小时内：决定留/退/换；退单书面申请，留聊天/快递记录。
- [ ] 一周内：预约门店看样/试纱/看场地。
- [ ] 把销售口头承诺补进补充协议。

## 5. 20 句砍价话术

### 酒店（6 句）

1. “服务费免掉、备用桌 2 桌可退，我今天可以付定金。”
2. “如果改到周日午宴，桌价和最低桌数能到什么水平？”
3. “LED 屏是 P3 还是 P4？含控台和播放员吗？外请团队收进场费吗？”
4. “婚房能不能升套房或多送一晚？停车券能给 40 张吗？”
5. “这份报价含税吗？税点、服务费、开瓶费、进场费请单独列一张纸。”
6. “台风红色预警改期，写进合同哪一条？”

### 婚庆（4 句）

7. “请按设计/搭建/花艺/灯光/人员/运输分项报价。”
8. “效果图里的吊顶和花艺，落地用什么材质？花量多少？能看同材质现场吗？”
9. “如果总预算砍 15%，你先减哪里？哪些不能减？”
10. “当天到场几个人？姓名/分工写进合同；换人需我们书面同意。”

### 四大（4 句）

11. “请给我看 2 场完整婚礼，不要混剪。”
12. “当天是本人吗？几个机位？有备用机身/双卡吗？”
13. “精修多少张？底片全送吗？加一张多少钱？交付多久？”
14. “超时费从几点算？每小时多少？”

### 婚纱照/婚博会（3 句）

15. “服装分不分区？高级区加多少钱？底片全送吗？”
16. “这个价格是展会专属还是门店同价？保价到什么时候？”
17. “订单写‘未签约可退’还是‘定金不退’？能盖主办方保障章吗？”

### 通用（3 句）

18. “这个价格能保留到什么时候？”
19. “如果我今天付定金，能多给什么？”
20. “把刚才说的写进合同/订单并盖章，可以吗？”

## 6. 订单条款检查（12 条）

- [ ] 合同主体 = 营业执照 = 收款账户 = 发票抬头
- [ ] 定金/订金性质与退款条件
- [ ] 价格保护期
- [ ] 套餐含项（人员/机位/精修/服装/场景/时长）
- [ ] 增项单价（加片/加机位/超时/运输）
- [ ] 人员姓名/级别/替换条款
- [ ] 交付时间/修改次数/底片归属
- [ ] 取消/改期/不可抗力
- [ ] 主办方订单保障是否适用
- [ ] 口头承诺写进备注并盖章
- [ ] 付款走对公账户，备注合同编号
- [ ] 订单/合同/报价单三份拍照存档
