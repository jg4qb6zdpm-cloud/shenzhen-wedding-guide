# 结构化数据说明

本目录存放可被表格/脚本复用的结构化基准数据。所有价格均为 **2026 年 Q4 深圳市场参考区间**，不是报价承诺。

## 口径

- 桌价：10 人/桌，仅菜品，不含服务费、税、酒水。
- 婚庆：设计 + 搭建 + 花艺 + 灯光 + 人员 + 运输撤场。
- 四大：司仪 + 摄影 + 摄像 + 化妆合计。
- 总预算：含婚宴、服务费、酒水、婚庆、四大、婚纱照、礼服、婚车、请柬伴手礼、杂项和 10% 备用金；不含婚房/购车/彩礼/蜜月。

## `price-tiers-2026.csv`（主数据）

三档价格标准（T1/T2/T3）的完整区间。

| 字段 | 含义 |
|---|---|
| `category` | 费用大类 |
| `item` | 费用项 |
| `t1_low/t1_high` | T1 标准档区间 |
| `t2_low/t2_high` | T2 品质档区间 |
| `t3_low/t3_high` | T3 高端档区间 |
| `unit` | 单位（元、元/桌、元/人、比例） |
| `basis` | 计价口径 |
| `note` | 上限/加项说明 |

## `budget-examples-2026.csv`

15/20/25 桌的三档样板预算合计，用于快速对照。

| 字段 | 含义 |
|---|---|
| `tier` | T1/T2/T3 |
| `tables` | 桌数 |
| `total_wan` | 总预算（万元，含 10% 备用金） |
| `note` | 测算假设 |

## `cost-benchmarks-2026.csv`

20 桌样板预算的**点估计**，用于填充预算表。区间与上限见 `price-tiers-2026.csv`。

| 字段 | 含义 |
|---|---|
| `category/item` | 费用大类/项目 |
| `t1/t2/t3` | 三档点估计 |
| `unit` | 单位 |
| `note` | 口径说明 |
| `source` | 依据 |

## `spec-tiers.csv`

四档规模（S1–S4）与品质档（T1–T3）的对应关系。

| 字段 | 含义 |
|---|---|
| `tier` | 规模档中文名 |
| `code` | S1–S4 |
| `t_tier` | 常见品质档 |
| `guests` | 建议宾客人数区间 |
| `tables` | 建议桌数区间（10 人/桌） |
| `table_price_low/high` | 每桌餐标参考区间（元/桌） |
| `budget_low/high_wan` | 婚礼执行预算区间（万元） |
| `venue` | 场地类型 |
| `planning` | 婚策/统筹模式 |
| `best_for` | 适合家庭 |
| `risk` | 主要风险 |

## `timeline.csv`

T-13 到 T+30 的任务清单，`step` 对应主线 10 步。

| 字段 | 含义 |
|---|---|
| `step` | 对应第几步（1–10） |
| `phase` | 阶段 |
| `window` | 时间窗口 |
| `task` | 任务 |
| `owner` | 主责人 |
| `output` | 交付物 |
| `gate` | 对应决策门（G1–G6） |

## 使用建议

- 用 `spec-tiers.csv` 选规模档，用 `price-tiers-2026.csv` 选品质档。
- 用 `budget-examples-2026.csv` 做 10 秒初筛，再用 `cost-benchmarks-2026.csv` 填明细。
- 所有值必须用实际书面报价替换；不要拿“起价”当成交价。
- 用 `timeline.csv` 导入飞书/Notion/Excel，`step` 列对应主线第 1–10 步，可直接生成项目任务。
- 修改数据后，同步更新 `docs/01-第1步-先谈清楚.md` 与 `docs/A-价格标准.md`。
