# 03｜预算模型与费用基准：钱到底花在哪里

> 婚礼预算最常见的错误，不是“花多了”，而是“不知道花在哪”。本章给你一套可复算的模型，而不是一张拍脑袋的报价单。

## 3.1 三层预算，不要混账

| 层级 | 包含内容 | 管理方式 |
|---|---|---|
| **家庭总投入** | 婚礼执行 + 彩礼/嫁妆 + 婚房/装修/购车 + 蜜月 + 其他 | 双方父母与新人共同确认，单独记账 |
| **婚礼执行预算** | 婚宴、场地、婚策、四大、婚纱、影像、婚车、请柬伴手礼等 | 由财务负责人统一管理，按合同付款 |
| **应急金** | 执行预算的 10%，用于加桌、超时、天气、临时人员 | 不轻易动用；动用需总协调人+财务负责人双签 |

> **建议：** 把“彩礼/嫁妆”从婚礼执行预算中完全分离。它不是婚礼费用，而是两个家庭之间的礼俗安排；混在一起，容易把感情问题变成财务问题。

## 3.2 2026 年深圳费用基准

以下为 2026 年 10 月深圳市场参考区间。**“经济”不等于低质，“旗舰”也不保证满意**；关键是服务清单和合同。

| 项目 | 经济 | 品质 | 高端 | 旗舰 |
|---|---|---|---|---|
| **婚宴/桌** | 3,000–5,000 | 5,000–8,000 | 8,000–15,000 | 15,000–30,000+ |
| **婚策/布置** | 0.8–2万 | 3–6万 | 8–20万 | 30–80万+ |
| **四大（司仪/摄影/摄像/化妆）** | 1.5–3万 | 3–5万 | 6–12万 | 15–30万+ |
| **婚纱照** | 0.5–1万 | 1–2万 | 2–5万 | 5–10万+ |
| **婚纱礼服（新娘+新郎）** | 0.5–1.5万 | 2–4万 | 5–10万 | 10–30万+ |
| **珠宝首饰（三金/钻戒）** | 2–5万 | 5–10万 | 10–30万 | 30–100万+ |
| **婚车** | 0.3–0.8万 | 0.8–1.5万 | 1.5–3万 | 3–8万+ |
| **请柬/伴手礼/喜糖** | 0.5–1万 | 1–3万 | 3–6万 | 6–15万+ |
| **备用金** | 执行预算的 10% | 同左 | 同左 | 同左 |

**价格锚点（公开信息，访问于 2026-10-29）：**

- 深圳婚礼纪商家列表显示：四星级酒店婚宴 **2,688 元/桌起**；婚礼堂 **3,990 元/桌起**；五星级酒店 **6,888 元/桌起**；社会餐饮 **3,999 元/桌起**。 [C]
- 同一平台深圳婚礼策划商家公开起价约 **8,888–19,998 元**；婚纱摄影套餐约 **1,000–7,999 元**。 [C]
- 2024 年深圳婚礼费用文章给出的基础婚礼总价为 **5–10 万元**，10 桌婚礼约 **10–21 万元**；婚礼堂婚宴 **1,988–3,988 元/桌起**。 [C]

> **重要：** 平台“起价”通常对应最基础配置、非热门日期、最小桌数。实际报价要把服务费、税费、最低桌数、指定供应商、设备租赁全部加回。

## 3.3 四档预算样例（可直接复算）

假设：10 人/桌；S1 10 桌、S2 20 桌、S3 30 桌、S4 40 桌；单位：万元。

| 项目 | S1（10桌） | S2（20桌） | S3（30桌） | S4（40桌） |
|---|---:|---:|---:|---:|
| 婚宴餐饮 | 3.8 | 14.0 | 36.0 | 80.0 |
| 服务费（10%/15%） | 0.38 | 1.4 | 3.6 | 12.0 |
| 婚策/布置 | 1.5 | 4.0 | 12.0 | 30.0 |
| 四大 | 2.0 | 3.5 | 6.0 | 12.0 |
| 婚纱礼服 | 1.2 | 2.0 | 4.0 | 8.0 |
| 婚纱照/影像 | 0.6 | 1.0 | 2.0 | 4.0 |
| 珠宝首饰 | 2.0 | 4.0 | 8.0 | 15.0 |
| 婚车 | 0.3 | 0.6 | 1.2 | 3.0 |
| 请柬/伴手礼 | 0.6 | 1.5 | 3.0 | 6.0 |
| 备用金 | 1.0 | 3.0 | 6.0 | 15.0 |
| **合计** | **13.4** | **35.0** | **81.8** | **185.0** |

**读法：**

- S1 的 13.4 万是“有珠宝、有跟拍、有 10 桌餐叙”的中位样例；压缩到 5–8 万也可行，但要去掉珠宝或大幅减桌。
- S2 的 35 万是“20 桌、四星/五星、全案婚策、完整四大”的中位样例；控制在 25 万需要降桌价或减设计。
- S3 的 81.8 万是“30 桌、五星/户外、定制设计、双机影像”的中位样例；100 万以上通常来自场地升级、花艺/灯光升级、名司仪、现场乐队。
- S4 的 185 万是“40 桌、地标酒店、顶级婚策、安保礼宾”的起点；多日/目的地/包场很容易到 250–300 万。

> 如果酒店报价已含服务费，删除“服务费”一行；如果服务费为 15%，按实际比例替换。所有金额以书面报价为准。

## 3.4 桌数与宾客数：最大的成本杠杆

### 计算公式

**预计到场人数 = 邀请人数 × 到场率**

参考到场率：

| 宾客类型 | 到场率参考 |
|---|---|
| 本地至亲/好友 | 85–95% |
| 本地普通亲友/同事 | 70–85% |
| 外地亲友 | 50–70% |
| 商务/泛社交宾客 | 50–70% |
| 长辈的朋友/家族关系 | 70–90% |

**桌数 = 预计到场人数 ÷ 10，向上取整 + 备用桌**

**备用桌 = max（1 桌，桌数 × 5–10%）**

### 示例

- 邀请 240 人，其中本地 160 人（到场 90%）、外地 80 人（到场 60%）：
  - 预计到场 = 160×0.9 + 80×0.6 = 144 + 48 = 192 人。
  - 基础桌数 = 19.2 → 20 桌。
  - 备用桌 = 2 桌。
  - 建议预订 22 桌，最终保证 20 桌。

### 三个规则

1. **酒店最低桌数/保底消费**可能高于你的实际需求；签约前算清“保底桌数 × 桌价 + 服务费”。
2. **备用桌**要问清“可退/可改期/可打包”，不是所有酒店都允许免费退。
3. **加桌价格**通常高于原桌价，且临近婚期可能无法加；合同里写死加桌单价和最晚确认时间。

## 3.5 隐形费用清单：报价单上最容易漏的 19 项

| 类别 | 项目 | 常见区间/说明 |
|---|---|---|
| 场地 | 服务费 | 10–15%，是否含税要确认 |
| 场地 | 开瓶费 | 100–300 元/瓶，自带酒水常见 |
| 场地 | 进场费/押金 | 2,000–10,000 元，部分可退 |
| 场地 | 超时费 | 按小时计，晚间 22:00 后常见 |
| 场地 | 电费/发电车 | 大功率灯光/LED 可能另计 |
| 场地 | 清洁费 | 布置垃圾/花瓣/烟雾残留 |
| 餐饮 | 备用桌 | 可退/不可退，差异很大 |
| 餐饮 | 加桌/加座 | 临近婚期加桌通常更贵 |
| 餐饮 | 儿童椅/宝宝椅 | 可能免费或按个收费 |
| 餐饮 | 员工餐/供应商餐 | 摄影、摄像、化妆、司仪、车队 |
| 餐饮 | 酒水/饮料 | 是否允许自带、是否收开瓶费 |
| 布置 | 非标搭建 | 桁架、地台、吊顶、T 台、异形结构 |
| 布置 | 花艺升级 | 鲜花品种、进口花、花量 |
| 设备 | LED/音响/灯光 | 酒店自带还是外租，型号与数量 |
| 设备 | 话筒/追光/烟雾机 | 数量、备用、操作人员 |
| 人员 | 超时费/加班费 | 摄影摄像、化妆、司仪、车队 |
| 人员 | 差旅/住宿 | 外地团队、目的地婚礼 |
| 其他 | 停车/代客泊车 | 宾客停车券、封顶费用 |
| 其他 | 版权/交付 | 底片、精修、视频时长、交付时间 |

> **谈判原则：** 不要只谈“总价”，要逐项谈“包含什么、数量多少、超了怎么算、什么时候付、不能交付怎么赔”。

## 3.6 付款节奏：尾款是你的杠杆

推荐结构（可按供应商类型调整）：

| 节点 | 比例 | 说明 |
|---|---:|---|
| 签约 | 30% | 锁定档期与团队 |
| 方案/菜单确认 | 30% | 设计定稿、试菜后 |
| 婚礼前 7 天 | 30% | 最终人数、流程确认后 |
| 交付/婚礼后 | 10% | 影像交付、账目结清后 |

**场地**通常要求：定金 20–30% → 试菜/确认 30% → 婚期前 7 天付清 → 押金另计。
**婚策/四大**建议保留 10% 尾款到婚礼结束/影像交付，写入合同。
**不要**在未看到书面服务清单、未确认人员姓名的情况下支付大额“诚意金”。

## 3.7 八个省钱杠杆（不牺牲体验）

1. **避开热门日期**：五一、国庆、520、七夕、周末晚宴最贵；工作日午宴/淡季可省 15–30%。
2. **减桌数**：每减 5 桌，通常释放 3–8 万元（含餐饮、布置、伴手礼、座位）。
3. **选婚礼堂/社会餐饮**：同样的菜金，场地可能比五星酒店低 30–50%。
4. **用酒店自带布置**：如果酒店/婚礼堂已有基础舞台、灯光、地毯，减少非标搭建。
5. **合并影像团队**：摄影+摄像同一团队，通常比分开请便宜，且协同更好。
6. **精简非核心环节**：车队、迎宾甜品、现场乐队、烟花/冷焰火，按优先级取舍。
7. **电子请柬 + 小份伴手礼**：把预算从“人手一份”转到“核心亲友”。
8. **淡季旅拍**：避开寒暑假/节假日，机票酒店便宜，拍摄体验更好。

## 3.8 不能省的五件事

1. **食品安全与留样**：菜单资质、食材规格、留样 48 小时。
2. **摄影摄像备份**：双卡/双机/备用电池，合同写清交付时间。
3. **当天总协调**：一个人对全场负责，避免“谁都管、谁都不管”。
4. **合同审查**：尤其是取消、改期、人员替换、隐形费用。
5. **天气/应急方案**：户外婚礼的室内备选、雨棚、发电、医疗。

## 3.9 预算控制五条铁律

1. **一张总表**：所有报价、合同、付款、尾款都在同一张表，指定一个财务负责人。
2. **一切书面**：微信语音不算，必须落到报价单/合同/确认单。
3. **10% 应急金**：不到万不得已不动；动用要双签。
4. **变更先签单**：现场加桌、加灯、加花，先确认价格再执行。
5. **每周对账**：至少每周一次，婚礼前两周每天一次。
