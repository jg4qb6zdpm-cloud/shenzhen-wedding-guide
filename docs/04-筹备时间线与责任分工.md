# 04｜筹备时间线与责任分工：按关键路径推进

> 婚礼筹备不是“事情越多越忙”，而是“有没有在正确的时间做正确的决定”。本章给出一条可执行的关键路径。

## 4.1 关键路径：哪几件事决定全局

**婚期 → 场地 → 婚策 → 四大 → 流程 → 彩排**

这条链上的任何一环延误，都会向后传导。尤其是：

| 事项 | 建议提前量 | 说明 |
|---|---|---|
| 热门场地/热门日期 | 8–12 个月 | 好日期先被订走，价格也更高 |
| 名司仪/摄影/摄像 | 6–10 个月 | 好团队档期有限，临时换人风险高 |
| 婚纱定制/高定礼服 | 3–6 个月 | 量体、试版、修改至少 2–3 轮 |
| 跨境婚姻文件 | 2–6 周（部分国家更久） | 公证、认证、翻译不可压缩 |
| 婚纱照 | 2–3 个月 | 拍摄 + 选片 + 精修 + 相册 |
| 婚策全案 | 4–8 个月 | 概念、方案、搭建、彩排 |

## 4.2 T-12 到 T+30 时间线

> T 日 = 婚礼当天；T-6 月 = 婚礼前 6 个月。以下按“12 个月筹备期”设计；如果只有 6 个月，把前两阶段合并，但不要跳过场地和合同。

| 阶段 | 时间 | 关键动作 | 交付物 | 责任人 |
|---|---|---|---|---|
| **0 立项** | T-12～T-11 | 家庭决策会；定规格、预算上限、婚期窗口、宾客上限 | 一页共识书 | 新人 + 父母 |
| **1 登记/婚检** | T-12～T-10 | 婚检预约；领证预约；跨境文件启动 | 婚检报告/领证日 | 新人 |
| **2 场地初筛** | T-11～T-10 | 看 3–5 家场地；对比桌数、层高、报价、档期 | 场地对比表、2 家意向 | 总协调 + 新人 |
| **3 场地签约** | T-10～T-9 | 谈最低桌数、服务费、备用桌、取消条款；付定金 | 场地合同 | 财务 + 新人 |
| **4 婚策签约** | T-10～T-8 | 看 3 家婚策；比稿/看现场；确认服务清单 | 婚策合同 | 新人 + 总协调 |
| **5 四大锁定** | T-8～T-6 | 司仪/摄影/摄像/化妆面试；看完整作品；签合同 | 四大合同 | 婚策 + 新人 |
| **6 婚纱/珠宝** | T-8～T-6 | 婚纱定制/租赁；新郎西装；三金/钻戒 | 订单/取件时间 | 新人 |
| **7 婚纱照** | T-7～T-5 | 选风格/团队；拍摄；选片；精修 | 婚纱照/相册 | 新人 |
| **8 名单/请柬** | T-6～T-4 | A/B/C 名单；电子请柬；纸质请柬；RSVP | 宾客名单初稿 | 父母 + 新人 |
| **9 菜单/试菜** | T-5～T-4 | 试菜；确认食材规格；酒水/开瓶费 | 菜单确认单 | 新人 + 场地 |
| **10 流程/布置** | T-4～T-3 | 仪式流程；设计定稿；座位表；伴手礼 | 流程表/座位图 | 婚策 + 总协调 |
| **11 礼服试穿** | T-3～T-2 | 婚纱/西装试穿；修改；婚鞋/配饰 | 取件完成 | 新人 |
| **12 最终确认** | T-2～T-1 | 最终人数；加桌/备桌；供应商到场时间；付款 | 执行手册 | 总协调 |
| **13 彩排** | T-7～T-1 | 走位；音乐；灯光；话筒；长辈接待 | 彩排记录 | 婚策 + 场地 |
| **14 婚礼日** | T | 按分钟流程执行 | 婚礼完成 | 总协调 |
| **15 收尾** | T+1～T+30 | 回门；答谢；影像交付；账目结算 | 交付清单/结算表 | 新人 + 财务 |

## 4.3 12 周倒计时清单

### T-12～T-9 周：定框架

- [ ] 完成“一页家庭共识书”。
- [ ] 确定 2–3 个候选日期段。
- [ ] 看 3–5 家场地，拿到书面报价。
- [ ] 确认婚检/领证时间。
- [ ] 建立预算总表、宾客名单表、供应商对比表。

### T-8～T-5 周：锁供应商

- [ ] 签场地合同，确认最低桌数/服务费/备用桌。
- [ ] 签婚策合同，确认设计/执行/人员清单。
- [ ] 锁定四大，确认姓名、档期、到场时间。
- [ ] 婚纱/西装下单，确认试穿和取件日期。
- [ ] 婚纱照拍摄，预约选片/精修。
- [ ] 确定请柬风格和发放时间。

### T-4～T-2 周：定细节

- [ ] 宾客名单锁定，RSVP 截止。
- [ ] 试菜，确认菜单、酒水、过敏原。
- [ ] 座位表初稿，主桌安排。
- [ ] 仪式流程、音乐、视频脚本。
- [ ] 伴手礼、喜糖、签到用品下单。
- [ ] 确认婚车路线、停车、接亲时间。

### T-1 周：总确认

- [ ] 最终人数/桌数，书面通知酒店。
- [ ] 所有供应商到场时间、联系人、车辆信息。
- [ ] 付款完成，尾款/押金记录。
- [ ] 天气预案，户外备选。
- [ ] 物资打包，编号。
- [ ] 彩排，确认走位/灯光/话筒。
- [ ] 分发“当天流程卡”和“应急联系表”。

## 4.4 RACI 责任矩阵

> R=执行，A=最终负责，C=被咨询，I=被知会。

| 事项 | 新人 | 父母 | 总协调 | 财务 | 婚策 | 场地 |
|---|---|---|---|---|---|---|
| 规格/预算上限 | A | C | C | R | I | I |
| 宾客名单 | A | R | C | I | I | I |
| 场地签约 | A | C | R | R | C | C |
| 婚策/四大 | A | I | R | C | R | I |
| 菜单/试菜 | A | C | C | I | C | R |
| 座位表 | A | C | R | I | C | I |
| 当天流程 | A | I | R | I | R | C |
| 付款/结算 | A | I | C | R | I | I |
| 长辈接待 | I | A | R | I | C | C |
| 应急决策 | A | I | R | C | C | C |

**关键原则：**

- **A 只能有一个人。** 每项决策明确“谁拍板”，避免“都可以”。
- **R 可以多人，但要有一个主 R。** 例如“宾客名单”由父母主 R，新人 A。
- **C 不是审批权。** 被咨询的人给意见，但不替 A 做决定。
- **I 不是“事后通知”。** 关键节点要提前知会，尤其是父母和财务。

## 4.5 六道决策门（Gate）

每道门不通过，不进入下一阶段：

| 门 | 时点 | 通过标准 | 不通过的风险 |
|---|---|---|---|
| **G1 规格与预算** | T-12 | 共识书签字；预算上限明确 | 后面所有报价都失锚 |
| **G2 场地与婚策** | T-9 | 合同签；服务清单/附件齐全 | 档期流失、价格被动 |
| **G3 四大与婚纱** | T-6 | 人员姓名/档期/交付写进合同 | 临时换人、作品不符 |
| **G4 名单与菜单** | T-4 | 人数/桌数/菜单/过敏原确认 | 加桌、超支、食品安全 |
| **G5 流程与彩排** | T-1 | 流程卡/分工表/应急表发到人 | 当天混乱 |
| **G6 结算与复盘** | T+1月 | 尾款结清；影像交付；账目归档 | 尾款纠纷、资料丢失 |

## 4.6 项目管理节奏

- **每周 30 分钟站会**：总协调、新人、婚策；只过“已完成/卡住/需要决策”。
- **一个共享总表**：预算、宾客、供应商、时间线放在同一份在线表格，避免多版本。
- **一个决策日志**：记录“谁在什么时候决定了什么”，减少反复。
- **一个变更单**：任何加桌、加项、换人，都写价格、时间、责任人。
- **一个文件命名规则**：`日期_供应商_文件类型_版本`，例如 `20261029_XX酒店_婚宴合同_v2.pdf`。

## 4.7 角色卡（可直接发给家人）

### 总协调人

- 对婚礼当天全流程负责，是现场唯一“总指挥”。
- 不参与具体布置，不做司仪/摄影的活。
- 持有最终流程表、供应商联系表、场地平面图、应急方案。
- 有权在预算范围内做现场决定；超出预算需联系财务/新人。

### 财务负责人

- 管理预算总表、合同、付款节点、发票。
- 所有付款前核对“合同/报价/验收”三件事。
- 保管尾款和应急金，不把现金交给多人。

### 长辈联络人

- 负责父母/长辈的接送、座位、敬茶顺序、合影安排。
- 提前告知长辈流程和时间，避免“找不到人”。
- 在礼俗冲突时，先安抚、再请示，不在现场争论。

### 伴郎/伴娘

- 伴郎：车队、红包、烟酒、现场跑腿、突发支援。
- 伴娘：新娘贴身、礼服/补妆、手机/首饰保管、敬茶协助。
- 不安排伴郎伴娘做“总协调”，他们当天也很忙。

> **本章行动：** 把时间线导入共享日历；确定总协调人、财务负责人、长辈联络人三个人选，并在家庭群公布。
