# 01｜先定规格，再定酒店

> 婚礼的第一个决策不是“选哪家酒店”，而是“我们要办成哪一档”。规格不清，所有报价都无法比较。

## 1.1 规格不是排场，是五种资源的组合

同样叫“在深圳办婚礼”，可能是 3 桌家宴，也可能是 50 桌地标酒店加三天行程。差异来自五个变量：

1. **宾客规模**：人数决定桌数，桌数决定场地和餐饮成本。
2. **桌单价**：社会餐厅、婚礼堂、五星酒店、地标酒店，单价可能相差 5–10 倍。
3. **场地类型**：室内宴会厅、户外草坪、滨海场地、游艇、目的地，带来不同的搭建、天气和交通成本。
4. **设计强度**：从“酒店自带布置”到“全案定制搭建”，预算可能从 1 万到 50 万以上。
5. **服务深度**：自己张罗、单点统筹、全案策划、家族事务团队，投入的人力和专业度不同。

**规格 = 宾客规模 × 桌单价 × 场地类型 × 设计强度 × 服务深度。**

## 1.2 先写死四条硬约束

在接触任何供应商之前，家庭内部先确认四个数字/边界：

| 硬约束 | 要写成什么 | 为什么重要 |
|---|---|---|
| **婚期窗口** | 例如“2027年3–5月，优先周六晚宴” | 直接决定档期、价格和可选场地 |
| **宾客上限** | 例如“不超过 220 人，最多 22 桌” | 桌数是最大成本杠杆，也能倒逼名单取舍 |
| **预算上限** | 例如“婚礼执行不超过 45 万，另留 5 万备用金” | 没有上限，报价永远会“再加一点” |
| **家庭红线** | 例如“必须保留敬茶”“不办户外”“不收彩礼” | 避免执行到一半才发现长辈不可接受 |

> **关键规则：预算上限必须在看场地之前确定。** 先看场地再定预算，等于让酒店替你决定花多少钱。

预算要分三层，不要混在一起：

- **家庭总投入**：婚礼执行 + 彩礼/嫁妆 + 婚房/装修/购车 + 蜜月 + 其他。
- **婚礼执行预算**：婚宴、场地、婚策、四大、婚纱、影像、婚车、请柬伴手礼等。
- **应急金**：执行预算的 10%，不轻易动用。

本文后续所说“预算”，除非特别说明，均指**婚礼执行预算**。

## 1.3 四档规格总表

| 档位 | 宾客/桌数 | 场地与团队 | 预算区间 | 适合家庭 |
|---|---|---|---|---|
| **S1 简约登记型** | 20–60人 / 2–6桌 | 社会餐厅、精品酒店小厅、婚礼堂小厅；轻婚纱或旗袍；领证跟拍；无婚策或单点统筹 | **5–15万** | 重视领证仪式、希望低调、宾客以至亲好友为主 |
| **S2 品质婚宴型** | 100–200人 / 10–20桌 | 四/五星酒店宴会厅或婚礼堂；全案婚策；完整四大；2–3套礼服 | **25–50万** | 需要正式宴请、兼顾体面与预算、第一次办婚礼 |
| **S3 高端定制型** | 180–300人 / 18–30桌 | 五星酒店、户外草坪/滨海场地、艺术空间；定制设计；名司仪/双机影像；现场乐队 | **60–120万** | 重视设计、体验、隐私，宾客结构多元 |
| **S4 家族旗舰型** | 250–500人 / 25–50桌 | 地标酒店、包场/多日、目的地婚礼；顶级婚策；安保与礼宾；跨城接待 | **150–300万+** | 家族社交属性强、需要多日安排、跨境/跨地域宾客多 |

> 表中预算不含婚房、购车、彩礼/嫁妆、蜜月。价格基准与测算方法见第3章。

## 1.4 四档分别“贵在哪”

### S1 简约登记型：把钱花在“人”和“照片”上

**典型配置：**

- 领证 + 至亲餐叙（2–6桌），可选小型颁证仪式。
- 场地：精品酒店小厅、社会餐厅包间、婚礼堂小厅。
- 服装：轻婚纱/旗袍/西装，1–2套。
- 影像：领证跟拍 + 餐叙记录，1位摄影师即可。
- 统筹：不请全案婚策，或只买“当天统筹”服务。

**钱主要花在：** 餐饮、摄影、服装、首饰。**不适合：** 200人以上、需要大面积定制布置、需要媒体接待。

### S2 品质婚宴型：把钱花在“稳定交付”上

**典型配置：**

- 10–20桌，四/五星酒店宴会厅或成熟婚礼堂。
- 全案婚策（设计+执行），四大齐全（司仪、摄影、摄像、化妆）。
- 2–3套礼服，婚纱照 1–2 组，婚车 6–8 辆。
- 有签到区、合影区、主舞台基础布置，流程完整。

**钱主要花在：** 婚宴、婚策、四大、影像。**关键不是“更豪华”，而是“不出错”。**

### S3 高端定制型：把钱花在“独特性”和“体验”上

**典型配置：**

- 18–30桌，五星酒店大宴会厅、户外草坪/滨海场地或艺术空间。
- 定制主题设计，非标搭建，灯光/音响/花艺升级。
- 名司仪或双司仪，摄影摄像双机/三机，现场乐队或弦乐。
- 宾客接待、住宿、交通、伴手礼整体设计。

**钱主要花在：** 设计、搭建、人员、影像、接待。**风险点：** 户外天气、搭建超时、供应商协同。

### S4 家族旗舰型：把钱花在“秩序”和“隐私”上

**典型配置：**

- 25–50桌，地标酒店包场/多日，或目的地婚礼。
- 顶级婚策 + 独立设计团队 + 舞台/灯光/音响/花艺多供应商协同。
- 安保、礼宾、车辆调度、媒体管理、跨境宾客接待。
- 可能包含欢迎晚宴、正日仪式、答谢宴、旅拍/蜜月。

**钱主要花在：** 场地、设计、人员、接待、安保。**核心能力：** 项目管理，而不是“买东西”。

## 1.5 规格选择决策树

按顺序回答四个问题：

1. **是否举办公开宴请？**
   - 否 → **S1**。
   - 是 → 下一题。
2. **宾客是否 ≤200 人，且婚礼执行预算 ≤50 万？**
   - 是 → **S2**。
   - 否 → 下一题。
3. **是否需要定制设计、户外/滨海场地、较强隐私保护？**
   - 是 → **S3**。
   - 否 → **S2 的高配版**（加预算在餐饮和人员，而不是堆布置）。
4. **是否需要多日安排、跨城/跨境接待、包场或 250 人以上？**
   - 是 → **S4**。
   - 否 → **S3**。

> **不要“跨级硬上”。** 如果预算低于某档下限，正确做法是降一档，而不是在同一档里砍掉食品安全、影像备份、当天统筹这些“不能省”的项目。

## 1.6 升级与降级规则

### 什么时候可以升级

同时满足三个条件才升级：

1. 预算上限可以提高 **20% 以上**，且不影响家庭其他目标。
2. 婚期还有 **至少 2 个月** 的缓冲。
3. 有一位**专职总协调人**（新人或家族成员），不是“大家都帮忙”。

### 降级时先砍什么

按以下顺序降级，尽量保留核心体验：

1. **先减桌数**（最有效，直接减少餐饮、场地、伴手礼、座位成本）。
2. **再降桌单价**（五星→高品质社会餐饮/婚礼堂）。
3. **再降设计强度**（非标搭建→酒店自带/半定制）。
4. **最后降人员数量**（三机→双机，乐队→弦乐三重奏）。

**不要砍：** 食品安全与留样、摄影双备份、当天总协调、合同审查、天气备用方案。

## 1.7 一次 90 分钟的家庭决策会

### 会前

- 发本文第1章和第3章作为预读材料。
- 每人写下三个“必须保留”和三个“可以放弃”。
- 明确会议目标：**只做五个决策，不讨论供应商细节。**

### 议程

| 时间 | 议题 | 输出 |
|---|---|---|
| 0–10 min | 说明目标与规则 | 确认“今天只定五件事” |
| 10–25 min | 宾客规模与结构 | 宾客上限、A/B/C 名单原则 |
| 25–40 min | 预算上限与出资结构 | 总上限、各方出资、应急金 |
| 40–55 min | 婚期窗口与城市/场地类型 | 2–3 个候选日期段、场地方向 |
| 55–70 min | 礼俗底线 | 必须保留/可以简化的仪式 |
| 70–85 min | 角色与授权 | 总协调人、财务负责人、长辈联络人 |
| 85–90 min | 复述与确认 | 一页共识书，所有人确认 |

### 会议规则

- 不在会上给供应商打电话，不现场比价。
- 一个人说完，另一个人再说；不打断。
- 所有“必须”都要能说出来源：是新人需求、父母期待，还是家族惯例。
- 会后 24 小时内发会议纪要；没有写下来的，不算决定。

## 1.9 六个常见误区

1. **“先看酒店，预算再说。”** 酒店会锚定你的预算，最后不是“花多少”，而是“还能借多少”。
2. **“按邀请人数订桌。”** 应按“预计到场人数”订桌，并留 5–10% 备用桌。
3. **“婚策越贵越省心。”** 贵不等于省心；关键是服务清单、现场团队和合同约束。
4. **“四大随便找一个。”** 司仪、摄影、摄像是不可逆的；当天没有重拍。
5. **“彩礼和婚礼预算是一回事。”** 两者性质不同，必须分账管理，避免家庭误会。
6. **“长辈的礼俗以后再补。”** 礼俗是长辈的安全感来源，越晚沟通，成本越高。
