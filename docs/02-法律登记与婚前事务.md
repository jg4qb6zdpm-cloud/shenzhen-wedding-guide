# 02｜法律登记与婚前事务：先把“夫妻关系”落地

> 婚礼可以延期，登记不能想当然。2025年5月10日起，结婚登记规则已经发生实质变化：全国通办、无需户口簿、免费办理。

## 2.1 2025年新规：四个必须知道的变化

依据国务院《婚姻登记条例》（国令第804号，2025年5月10日施行）和民政部《婚姻登记工作规范》（民发〔2025〕23号）：

| 变化 | 新规则 | 对备婚的意义 |
|---|---|---|
| **全国通办** | 内地居民结婚，可在全国任一婚姻登记机关办理，不再受户籍地限制 | 非深户可以在深圳领证，不必回老家 |
| **不再用户口簿** | 内地居民只需居民身份证 + 无配偶/无近亲声明 | 材料大幅简化，集体户/家庭户都不必借户口本 |
| **免费办理** | 婚姻登记机关办理婚姻登记，不得收取费用 | 任何“加急费/工本费/服务费”都要警惕 |
| **当面声明** | 双方亲自到场，现场填写声明书、签名并按指纹 | 不能代办，不能只带复印件 |

> **注意：** “全国通办”适用于内地居民之间的结婚登记。涉港澳台、华侨、外国人的婚姻登记，仍由省级民政部门或其指定机关办理，材料与流程不同。[A]

## 2.2 在深圳领证：材料与条件

### 受理条件

- 男女双方亲自共同到婚姻登记机关提出申请。
- 男方年满 22 周岁，女方年满 20 周岁；生日当天可以受理。
- 双方均无配偶（未婚、离婚、丧偶）。
- 双方无直系血亲和三代以内旁系血亲关系。
- 双方自愿结婚。
- 持有规定的有效身份证件和书面材料。

### 内地居民所需材料

1. **本人有效居民身份证**（临时身份证也可）。
2. **3 张 2 寸双方近期半身免冠同版合影证件照**，深圳常见要求为红底。
3. 现场签署**无配偶及无直系血亲/三代以内旁系血亲关系声明**。

**不需要：** 户口簿、深圳居住证、婚育证明、单位证明。[A][B]

> **照片注意：** 必须是证件照，不能使用婚纱照、剧照、艺术照；3 张必须同版。建议提前到照相馆说明“结婚登记照”，并保留电子版。

## 2.3 预约：15 天号源，每天 8:30 放号

深圳婚姻登记实行预约优先，也可在预约已满时到现场排队（以现场受理为准）。

| 项目 | 规则 |
|---|---|
| 预约渠道 | 广东省婚姻登记网上预约系统：https://www.gdhy.gov.cn/ |
| 放号时间 | 每天 8:30 |
| 可预约范围 | 提前 1 天起，可预约 15 天内的号源 |
| 取消 | 不能按约办理的，应提前 1 天以上取消 |
| 爽约 | 30 天内 2 次预约成功未到场且未取消，视为爽约；爽约之日起 15 天后才能再预约 |
| 现场排队 | 预约已满时可直接到婚姻登记处现场排队，建议工作日上午前往 |

**热门日期：** 2月14日、5月20日、5月21日、七夕、10月10日、11月11日。热门日期号源紧张，建议在放号第一时间预约，并准备“次选日期 + 次选登记处”。

## 2.5 现场流程：约 30–60 分钟

1. **取号/签到**：按预约时段到场，出示身份证。
2. **初审**：工作人员核对身份、婚姻状况、材料。
3. **填表**：现场填写《申请结婚登记声明书》，签名并按指纹。
4. **联网核对**：人证比对、婚姻状况核验。
5. **发证**：当场打印结婚证，双方各持一本；可申请免费颁证仪式。

**颁证仪式：** 婚姻登记机关可以为有意愿的当事人免费提供颁证仪式，鼓励邀请双方父母参加。部分登记处有特色颁证厅/户外颁证点，建议预约时询问。 [A]

## 2.6 特殊情形：港澳台、华侨、外国人

这类婚姻登记不属于“内地居民全国通办”，需要到**省级民政部门或其指定机关**办理。以深圳为常住地的情况，先向深圳市民政局确认办理权限，再准备材料。

常见材料逻辑（具体以官方清单为准）：

- **香港/澳门居民**：有效通行证或居住证 + 当地身份证 + 经公证的无配偶及无近亲声明。
- **台湾居民**：有效通行证或其他旅行证件/居住证 + 台湾身份证 + 经公证的声明。
- **华侨**：有效护照 + 居住国公证/认证的无配偶及无近亲证明（或中国使领馆证明）+ 中文译文。
- **外国人**：有效护照或永居证 + 所在国公证/认证的无配偶证明（或该国驻华使领馆证明）+ 中文译文。

> **时间提醒：** 跨境文件的公证、认证、翻译通常需要 2–6 周，部分国家更久。婚期确定后，应优先启动这部分，而不是先订酒店。

## 2.7 免费婚检：深圳的“二检合一”

深圳将免费婚前医学检查与孕前优生健康检查合并实施，检查项目基本相同，区别在服务对象和时期。 [B]

### 谁可以享受

| 类型 | 对象 | 说明 |
|---|---|---|
| **免费婚前医学检查** | 一方或双方为深圳户籍，准备登记结婚的男女双方 | 各区执行有差异；部分区对非深户也有条件开放 |
| **免费孕前优生健康检查** | 一方或双方为深圳常住人口，计划怀孕的夫妇 | 每孩次享受一次；一年内未接受过免费婚检/孕检 |

**非深户提示：** 如果一方有深圳居住证或社保参保证明，通常可以走免费孕前优生检查路径，项目与婚检相近；是否能出具“婚检证明”，需问具体医院。**先电话咨询，再预约。**

### 检查什么

- 基础体检：身高、体重、血压、心率等。
- 生殖系统检查：男女各有专属项目。
- 传染病筛查：乙肝、梅毒、艾滋病等。
- 遗传病筛查：地中海贫血、G6PD 等（深圳高发，重点项）。
- 优生健康教育、病史询问、风险评估、咨询指导。

### 怎么预约

1. 关注各区妇幼保健院公众号，进入“预约挂号”→“孕产保健科”→“婚前/孕前医学检查门诊（免费）”。
2. 双方分别预约；到现场后在“深圳妇儿通”小程序完成婚前孕前预建档。
3. 携带双方身份证；非深户按医院要求带居住证/社保卡/参保证明。
4. 女方避开月经期；B 超需憋尿；一般不需要空腹（以医院通知为准）。
5. 领取检查结果和评估建议。

**一站式便利：** 龙岗、龙华、罗湖等区在婚姻登记处旁边设置了婚检中心/婚检驿站，可以领证、婚检当天一起办理。 [B]

> **建议顺序：** 先婚检（提前 1–2 周预约）→ 再领证。若时间来不及，也可以领证后补孕前检查，但“婚检证明”可能无法补出，需提前问清。

## 2.8 婚前法律与财务清单

这部分不是“婚前算计”，而是把重大事项提前说清楚，避免婚后才发现信息不对称。涉及具体条款，请咨询执业律师。

- [ ] **重大疾病告知**：一方患有重大疾病的，应在结婚登记前如实告知另一方；未如实告知的，另一方可以依法请求撤销婚姻。 [A]
- [ ] **婚前财产清单**：房产、车辆、股权、基金、保险、债务、境外资产，各自列明归属与凭证。
- [ ] **婚前财产约定**：如涉及家族企业股权、房产加名、父母出资，建议书面约定并咨询律师。
- [ ] **债务与担保**：是否有经营贷、信用贷、对外担保、民间借贷；避免婚后被动承担。
- [ ] **父母出资性质**：赠与还是借款？给一方还是双方？最好有书面说明。
- [ ] **保险受益人**：重疾险、寿险、意外险的受益人是否需要调整。
- [ ] **公司/股权**：是否存在代持、对赌、回购义务；婚姻变动对股权结构的影响。
- [ ] **跨境因素**：税务居民身份、境外婚姻效力、外汇与资产申报。

> **原则：** 先披露，再约定；先写清，再签字。不要把“谈钱”等同于“不信任”，真正伤感情的是婚后才发现的隐瞒。

## 2.9 婚假：广东 3 天，原则上一次性休

依据《广东省职工假期待遇和死亡抚恤待遇规定》（粤人社规〔2023〕17号）：

- 职工本人结婚，可享受**婚假 3 天**。
- 双方不在一地工作的，可根据路程远近给予**路程假**，交通费自理。
- 婚假原则上**一次性连续安排**。
- 假期内遇法定休假日、休息日，**不另加假期天数**。
- 鼓励用人单位给予优于法定标准的假期。 [A]

**排期建议：**

- 领证日和婚礼日分开的，提前和 HR 确认婚假使用期限（有的单位要求领证后一年内）。
- 婚礼在异地/境外的，把路程假、年假、调休一起排，不要只按 3 天做计划。
- 婚礼当天需要早起的，提前 1–2 天请假，避免前一天还在上班。

## 2.10 领证日执行清单

- [ ] 提前 15 天预约，热门日期设闹钟 8:30 抢号。
- [ ] 双方身份证原件 + 3 张 2 寸红底合影照。
- [ ] 穿浅色/同色系衣服，避免与红底冲突；带一件外套。
- [ ] 预约跟拍摄影师（如需），确认登记处是否允许拍摄。
- [ ] 带一点喜糖/红包，给工作人员和同行亲友（自愿，不勉强）。
- [ ] 提前查好停车/地铁；热门登记处周边可能拥堵。
- [ ] 领证后检查姓名、身份证号、照片、登记日期。
- [ ] 把结婚证拍照备份，原件收好；后续买房、贷款、签证都会用到。

> **本章行动：** 今天确认三件事——双方户籍/证件是否一致、婚检是否要做、热门日期是否要抢。然后把领证日写进家庭日历。
