| 阶段 | 时间 | 这一章讲什么 | 交付物 |

## 阅读约定

- **每步同一节奏**：3 件事 → 时间/钱/交付物 → 怎么做 → 最容易踩的坑 → 检查清单 → 关门条件。
- **标记**：`[A]` 官方文件、`[B]` 政府服务指南、`[C]` 商业平台/市场、`[D]` 媒体案例。
- **价格**：2026 年 Q4 深圳市场参考区间，不是报价承诺；签约前用书面报价替换。
- **交叉引用**：正文用“第 N 步”“附录 X”指路，点本页表格即可跳转。
- **只读当前**：读完当前阶段，去做；做完再读下一步，不必从头读到尾。
